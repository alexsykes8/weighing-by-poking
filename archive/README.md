# Archive

Old work kept for the record, not needed to reproduce the README.

- `readme_v1/`: the first README (angled pokes, synthetic trajectories), its design notes, and its validation outputs (`out/compare_b8eb`, `out/discretisation.*`).
- `angled_v1/`: the first VLA, trained on angled pokes ("push the heaviest/lightest", `heaviest_v1`): its evals and launch script.
- `scripts/`: one-off launchers for overnight runs and restarts. They `cd` relative to `scripts/`, so they will not run from here as they are.
